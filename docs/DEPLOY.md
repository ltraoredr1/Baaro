# Déploiement BAARO

## Prérequis

- Compte Supabase
- Compte Vercel
- Clé Anthropic (Claude)
- Clé Cloudflare Turnstile (optionnel mais recommandé)

## Étapes principales

1. Créer le projet Supabase et exécuter les SQL dans l'ordre
2. Configurer les variables d'environnement
3. Déployer sur Vercel
4. (Optionnel) Générer l'app Android/iOS avec Capacitor
