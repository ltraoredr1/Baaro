4. Parcourir `AUDIT.md` (tests A/B)

## Compatibilité client

`AppContext.earnPoints(actionKey, detail, referenceId)` reste compatible.

Réponse `earn` enrichie :
- `credited` : points réellement crédités (catalogue + plafond)
- `balance` : solde serveur après écriture

Aucun changement obligatoire dans les composants UI, tant qu’ils n’envoient pas de montants.
